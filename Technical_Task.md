Техническое задание / Промпт для нейросети: создание воксельной Action-RPG для Android

1. Введение и цель

Цель: Разработать полноценную воксельную игру в жанре Action-RPG с открытым миром, процедурной генерацией, системой прокачки и сенсорным управлением, предназначенную для запуска на Android-устройствах. Разработка ведётся полностью в среде Termux с использованием нативных инструментов Android NDK.

Юридические ограничения: Игра должна давать игроку опыт, похожий на Cube World (исследование, бои в реальном времени, воксельная графика, прокачка), но категорически отличаться от неё по следующим пунктам:

· Уникальное название, логотип, названия классов, рас, мобов, предметов.
· Оригинальная боевая система (например, комбо-система с накоплением «резонанса», а не просто удары).
· Собственный художественный стиль (цветовая палитра, формы вокселей).
· Иные механики прогрессии (например, прокачка через «Древо Познания» вместо артефактов).
· Запрещено использование любых ассетов, кода или названий из оригинальной игры.

2. Общее описание игры

· Жанр: Воксельная Action-RPG с открытым миром.
· Перспектива: Вид от третьего лица (с возможностью переключения на первое).
· Платформа: Android (ARM64), минимальная версия API 24 (Android 7.0).
· Язык программирования: C++20 (с возможными ассемблерными вставками для критичных участков).
· Графический API: Vulkan 1.1 (приоритет) или OpenGL ES 3.2 (запасной вариант).
· Сборка: Termux + Android NDK + CMake + Clang.
· Целевая производительность: Стабильные 60 FPS на устройствах среднего сегмента (Snapdragon 660 и выше), потребление ОЗУ не более 1.5 ГБ, время генерации чанка не более 16 мс.

3. Технические требования

3.1. Среда разработки (Termux)

· Установить пакеты: termux-ndk, cmake, ninja, git, clang, vulkan-loader-android, shaderc, glm, entt (или flecs).
· Настроить переменные окружения: ANDROID_NDK_HOME, PATH.
· Использовать gradle для сборки APK или ручную упаковку через aapt2, d8, apksigner.
· Скрипты сборки должны быть в репозитории (build.sh, CMakeLists.txt).

3.2. Архитектура

· ECS (Entity-Component-System): Обязательно. Использовать EnTT или Flecs. Компоненты — POD-структуры, системы — чистые функции.
· Job System: Собственная реализация или Taskflow для многопоточной генерации чанков, мешей, ИИ.
· Управление памятью: Пулы объектов, арены, избегать new/delete в игровом цикле. Использовать std::pmr.
· Рендеринг: Многопоточная подготовка команд, двойная буферизация, отложенный рендеринг (deferred) или форвард+ с кластеризацией.
· Физика: Простая воксельная коллизия (AABB), без сторонних движков.

3.3. Оптимизация графики (приоритет №1)

· Greedy Meshing: Объединение соседних граней одного типа в один полигон.
· Face Culling: Не рендерить грани, скрытые соседними блоками.
· LOD (Level of Detail): 4 уровня детализации для чанков (0 — полный, 3 — упрощённый до 1/8).
· Frustum Culling: Отсечение чанков вне пирамиды видимости.
· Occlusion Culling: Использовать программный или аппаратный (Vulkan conditional rendering).
· Инстансинг: Для травы, листвы, мелких объектов.
· Шейдеры: Минимизировать ветвления, использовать mediump где возможно, предвычислять освещение (запекание в вершины).
· Текстуры: Атлас воксельных текстур, сжатие ASTC 4x4.
· Целевые метрики: Draw calls < 500 на кадр, вершины < 1 млн, заполнение < 2x overdraw.

3.4. Структура мира

· Чанки: Размер 32x32x32 вокселя. Хранение в HashMap с ключом (x, z).
· Воксели: uint16_t для ID блока (до 65536 типов). Отдельный массив для метаданных (поворот, состояние).
· Генерация: 3D Simplex Noise + комбинация слоёв (высота, пещеры, биомы, руды). Seed — 64-битное число.
· Биомы: Лес, пустыня, тундра, горы, океан, вулканический, болото. У каждого свои блоки, мобы, ресурсы.
· Структуры: Деревни, подземелья, алтари, руины. Генерируются по seed с проверкой на пересечения.

4. Геймплей

4.1. Прогрессия

· Уровни: Опыт за убийство мобов, выполнение квестов, исследование. Максимальный уровень — 100.
· Древо Познания: Три ветки: «Сила» (урон, здоровье), «Ловкость» (скорость, уклонение), «Мудрость» (мана, крафт). Очки навыков за уровень.
· Атрибуты: Сила, Ловкость, Интеллект, Выносливость. Влияют на урон, скорость атаки, ману, здоровье.
· Снаряжение: Оружие, броня (шлем, нагрудник, поножи, сапоги), аксессуары (кольца, амулеты). Редкости: обычное, необычное, редкое, эпическое, легендарное.
· Крафт: Рецепты открываются с уровнем. Требуются ресурсы и станции (наковальня, верстак, алхимический стол).

4.2. Оружие (воксельные модели)

· Ближний бой: Мечи (быстрые, средний урон), топоры (медленные, высокий урон), копья (дальний укол), кинжалы (быстрые, низкий урон, высокий шанс крита).
· Дальний бой: Луки (натяжение, траектория), арбалеты (мощный выстрел, перезарядка), метательные ножи.
· Магия: Посохи (снаряды), жезлы (АоЕ), браслеты (баффы/дебаффы).
· Особенности: Каждое оружие имеет уникальную анимацию замаха и частицы. Возможность зачарования (огненный, ледяной, электрический урон).

4.3. Квесты

· Генерация: На основе seed и текущего состояния мира. Типы: «Убей N мобов вида X», «Принеси N ресурсов Y», «Исследуй локацию Z», «Защити NPC».
· Выдача: У NPC-квестодателей в деревнях. Диалоговое окно с текстом, сгенерированным по шаблонам.
· Награды: Опыт, золото, случайный предмет, репутация с фракцией.
· Дневник квестов: Список активных и выполненных заданий с отметками на карте.

4.4. NPC

· Торговец: Продаёт/покупает предметы, обновляет ассортимент раз в игровой день.
· Кузнец: Крафт и улучшение оружия/броня.
· Квестодатель: Выдаёт квесты, продвигает сюжет.
· Стражник: Защищает деревню, атакует враждебных мобов.
· Диалоги: Простые, с ветвлением (2-3 варианта ответа). Реакция на репутацию.

4.5. Мобы

· Пассивные: Овцы, коровы, куры (дают ресурсы). Убегают при атаке.
· Агрессивные: Волки, скелеты, гоблины, слизни. Патрулируют, преследуют, атакуют.
· Боссы: Уникальные мобы в подземельях. Имеют несколько фаз, особые атаки.
· ИИ: Конечный автомат (Idle, Patrol, Chase, Attack, Flee). Использование A* для навигации по воксельной сетке.
· Спавн: В зависимости от биома, времени суток, освещения.

4.6. Сохранение и загрузка

· Профили: 3 независимых профиля. В каждом — 3 слота сохранения.
· Формат: Бинарный (сжатый zlib) или JSON (для отладки). Сохранять: seed мира, изменения чанков (дельты), позицию игрока, инвентарь, навыки, квесты, репутацию, время.
· Автосохранение: Каждые 5 минут и при выходе.
· Загрузка: Быстрая, с прогресс-баром. Асинхронная подгрузка чанков.

5. Управление (сенсорное)

5.1. Основные элементы

· Плавающий джойстик: Левый нижний угол. Появляется при касании. Перемещение персонажа.
· Камера: Свайп по правой половине экрана. Вращение камеры.
· Кнопки действий:
  · Атака (основная) — правая нижняя.
  · Прыжок — рядом с атакой.
  · Взаимодействие (E) — контекстная, появляется при наведении на объект.
  · Инвентарь — верхний правый угол.
  · Карта — верхний правый угол.
  · Меню — верхний левый угол.
· Дополнительные кнопки: Смена оружия (колесо), использование зелья, блок/парирование.

5.2. Настройка управления

· Размер и прозрачность всех элементов.
· Расположение: Свободное перемещение кнопок по экрану.
· Чувствительность камеры: Ползунок от 0.1 до 5.0.
· Инверсия осей: По X и Y.
· Лево/правша: Зеркальное отражение интерфейса.
· Геймпад: Поддержка Bluetooth-геймпадов (опционально).

6. Интерфейс (UI)

· HUD: Полоса здоровья (красная), маны (синяя), выносливости (зелёная). Шкала опыта. Мини-карта с компасом. Текущий квест.
· Меню: Главное (Новая игра, Загрузить, Настройки, Выход). Пауза. Инвентарь (сетка 6x4). Крафт. Древо Познания. Карта мира.
· Адаптация: Под разные разрешения и соотношения сторон (16:9, 18:9, 20:9). Использовать якоря и масштабирование.

7. Звук

· Звуковые эффекты: Шаги, удары, выстрелы, каст, взрывы, открытие сундуков. Формат OGG.
· Музыка: Динамическая, 3-4 трека (мирная, боевая, подземелье, деревня). Плавные переходы.
· Аудио-движок: OpenSL ES или AAudio.

8. Сборка в Termux

8.1. Подготовка

```bash
pkg install termux-ndk cmake ninja git clang
export ANDROID_NDK_HOME=$PREFIX/lib/android-ndk
```

8.2. CMakeLists.txt (пример)

```cmake
cmake_minimum_required(VERSION 3.20)
project(VoxelGame)

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

add_library(native-lib SHARED
    src/main.cpp
    src/renderer.cpp
    src/world.cpp
    src/ecs.cpp
    # ...
)

target_link_libraries(native-lib
    android
    log
    vulkan
    GLESv3
    EGL
)
```

8.3. Сборка APK

· Использовать gradle с externalNativeBuild.
· Или ручная сборка: aapt2 compile, aapt2 link, d8, apksigner.
· Скрипт build.sh должен собирать .so, упаковывать в APK, подписывать debug-ключом.

10. Задание для нейросети (пошаговый промпт)

Ты — опытный разработчик игр на C++ для Android. Твоя задача — создать игру по данному ТЗ. Работай поэтапно:

1. Настройка проекта: Создай структуру папок, CMakeLists.txt, скрипты сборки для Termux.
2. Окно и Vulkan: Инициализируй Vulkan (или OpenGL ES), создай поверхность, устройство, swapchain. Настрой рендеринг простого треугольника.
3. Воксельный рендеринг: Реализуй класс Chunk, генерацию меша с greedy meshing и face culling. Нарисуй один чанк.
4. Генерация мира: Добавь шум Перлина/Симплекса, генерацию чанков вокруг игрока, биомы.
5. ECS и игрок: Создай сущность игрока, компоненты Transform, Camera, Input. Реализуй движение и коллизию.
6. Сенсорное управление: Обработай касания, создай плавающий джойстик и кнопки. Свяжи с движением и камерой.
7. Мобы и NPC: Добавь простой ИИ (патрулирование, преследование). Реализуй спавн.
8. Боевая система: Добавь оружие, анимации, урон, здоровье.
9. Прогрессия: Реализуй опыт, уровни, древо навыков.
10. Квесты: Генерация квестов, диалоги, дневник.
11. Сохранения: Реализуй сериализацию мира и персонажа. 3 профиля, 3 слота.
12. Оптимизация: Профилируй, оптимизируй узкие места (LOD, многопоточность).
13. UI: Создай HUD, меню, инвентарь.
14. Звук: Подключи OpenSL ES, добавь звуки.
15. Финальная сборка: Собери APK, протестируй на устройстве.

Требования к коду:

· Чистый, модульный, с комментариями.
· Никаких утечек памяти.
· Использование современных практик C++20.
· Все критические секции — потокобезопасны.

Ожидаемый результат: Полный исходный код проекта, скрипты сборки, документация, готовый APK для установки на Android.
