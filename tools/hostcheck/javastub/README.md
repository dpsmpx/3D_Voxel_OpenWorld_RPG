# Заглушки Android для проверки Java

Java в проекте ровно один класс — активность с системным выбором
файла. Компилятору для него нужен `android.jar`, а его в окружении
проверки нет: SDK ставится только на сборку APK.

Здесь лежит ровно то, чего касается наш класс, и ничего сверх.
Заглушка не эмулирует Android — она даёт компилятору подписи, чтобы
он поймал опечатку в имени метода, лишнюю запятую и несовпадение
типов. Всё остальное поймает сборка APK.

Добавили в активность новый вызов Android — допишите его подпись
сюда, иначе проверка упадёт «cannot find symbol», и это правильно:
неизвестный вызов лучше увидеть здесь, чем в CI через двадцать минут.
